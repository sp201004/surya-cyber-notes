## Security Principles Quick Reference

| Concept | Key fact |
|--------|----------|
| **CIA Triad** | Confidentiality, Integrity, Availability — the three security goals |
| **DAD Triad** | Disclosure, Alteration, Destruction — the attacker's mirror of CIA |
| **Bell-LaPadula** | Confidentiality; No Read Up, No Write Down |
| **Biba** | Integrity; No Read Down, No Write Up |
| **Clark-Wilson** | Integrity via well-formed transactions + separation of duties |
| **Defence-in-Depth** | Layered controls; no single point of failure |
| **ISO/IEC 19249** | Domain separation, layering, encapsulation, redundancy, virtualization |
| **Zero Trust** | Never trust, always verify |
| **Threat/Risk/Vuln** | Vulnerability = weakness; Threat = potential exploiter; Risk = likelihood × impact |

> **Security relevance:** the models are mirror images — Bell-LaPadula protects *confidentiality* (no read up / write down), Biba protects *integrity* (no read down / write up).

## Careers in Cyber Quick Reference

| Concept | Key fact |
|--------|----------|
| **Skills gap** | Millions of unfilled roles; the field needs more skilled people |
| **Diversity** | Cyber security needs varied backgrounds and ways of thinking |
| **Soft skills** | Communication and explaining risk matter as much as technical skill |
| **Certifications** | Validate fundamentals; hands-on labs prove practical ability |
| **Roles** | Penetration Tester, Incident Responder, SOC Analyst, Security Engineer |
| **Progression** | Careers are flexible; the first role doesn't fix your path |

The starting path: `Learn fundamentals → Practise in labs → Build projects → Earn certifications → Specialise`.

> **Security relevance:** there is **no single "best" role** — offensive, defensive, engineering and GRC all matter; choose the work you enjoy.

## Training Impact Quick Reference

| Concept | Key fact |
|--------|----------|
| **Why train** | Most efficient way to raise skills and team capacity |
| **Juniors** | Training is the fastest way to ramp up a junior hire |
| **Teamwork** | Shared training and CTFs build team relationships |
| **Org size** | Small teams = broad/flexible; large orgs = role-specific/centralised |
| **Customisation** | Avoid one-size-fits-none and outdated material |
| **ROI formula** | ROI = Gain / Cost × 100 |
| **Savings ≠ ROI** | Savings is the benefit amount; ROI is that benefit relative to cost |

Worked ROI (task scenario): savings = 20 × $50,000 × 4% = **$40,000**; training cost = 20 × $500 = **$10,000**; `ROI = 40,000 / 10,000 × 100 = 400%`.

> **Security relevance:** framing training as an **investment** with a clear ROI is how a business case gets approved.
